連線到交通資料伺服器

在電腦上執行 npm run server 啟動伺服器；第一次啟動時畫面上會印出管理者權杖（也存在 apps/server/data/config.json）。

TDX 帳號

即時交通資料來自交通部「TDX 運輸資料流通服務」，需要免費會員帳號：到 tdx.transportdata.tw 註冊後，在「會員中心 → 資料服務 → API 金鑰」取得 Client ID 與 Client Secret。金鑰只存在伺服器上，不會送到網頁版。

資料來源

勾選要抓取的資料；更新間隔太短可能超過 TDX 的呼叫次數限制（每個來源有最短間隔）。
