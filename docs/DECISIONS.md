# 技術決策紀錄

每個重要決定一條：日期、決定、理由、代價。推翻舊決定時新增一條，不刪舊的。

## 2026-10-08　用 TypeScript monorepo，套件不另外建置

- **決定**：所有程式用 TypeScript；`packages/*` 直接匯出 `src/index.ts`，由 Vite 與 tsx 直接執行。
- **理由**：Claude 在這個組合上最能「自己寫、自己跑、自己驗證」；網頁版、批次腳本、資料管線共用同一份程式。
- **代價**：效能敏感的部分以後可能要改用 Rust 或 C++ 編成 WebAssembly。

## 2026-10-08　模擬與畫面分離，結果可重現

- **決定**：`sim-core` 不碰畫面；只用自己的亂數；tick 順序固定。
- **理由**：可以無畫面批次調平衡、存檔重播，也為之後的商用版（數位孿生）保留同一個核心。
- **代價**：畫面要的東西都得經過 snapshot，不能直接讀模擬內部。

## 2026-10-08　免費試玩版以高雄市為舞台

- **理由**：範圍適中（38 區），有海、平原、山區，地形變化完整。
- **代價**：數值與鏡頭先只針對高雄調整；擴到其他縣市時要再檢查。

## 2026-10-09　資料管線改用 Node（取代 Python 版）

- **決定**：自己寫 Shapefile/DBF 讀取與 TWD97 轉換（`packages/geo`），不用 GeoPandas。
- **理由**：使用者只需要安裝 Node；Windows 上安裝 GeoPandas 容易出問題。
- **代價**：複雜的空間運算（例如多邊形聯集）要自己寫或另外找套件。

## 2026-10-09　地圖改用 MapLibre GL（取代 three.js 手刻版）

- **決定**：用 MapLibre GL v5 畫地圖：OSM 向量底圖 + DEM 地形 + 山體陰影 + 3D 建築。
- **理由**：使用者的目標畫面是軌島（railisland.tw）那種真實地景；河流、海岸、湖泊、山、建築都是 OSM 向量資料內建，不必自己做。three.js 版的浮空台座與連線不符合期待。
- **代價**：特殊 3D 效果（例如爆炸、粒子）較難做；需要時可用 MapLibre 的 custom layer 混入 three.js。

## 2026-10-09　底圖用 OpenFreeMap

- **理由**：免費、免金鑰、允許商用，可完整自架（階段 4 會自架）。
- **代價**：公共服務沒有服務保證；樣式要自己維護（階段 1.1）。

## 2026-10-09　公開 repo、GitHub Pages 線上版、GoatCounter 統計

- **決定**：repo 維持公開；推送到 `main` 自動部署到 GitHub Pages；線上版用 GoatCounter 統計瀏覽數。私人文件（`*.docx`）不進版控。
- **理由**：使用者在筆電上透過雲端開發，沒有本機開發環境，開網址就能看畫面最方便；公開 repo 才能免費用 Pages。GoatCounter 免費、不用 cookie，不需要同意視窗。
- **代價**：程式碼與打包內容任何人都看得到，不能放金鑰；想看新改動要先合併到 `main`。設計文件 .docx 曾誤推上公開 repo，已改寫歷史移除。
