# 開發路線圖

最後更新：2026-10-09

目前重點是「立體、好看、真實的高雄場景」，遊戲性之後再回來。
路線依序是：開發基礎 → 地景精修 → 真實資料 → 遊戲性 → 公開試玩 → 擴張。
每一項都切成能在一次 Claude Code 對話內完成的大小，並寫好驗收方式。

## 現況（2026-10-09）

| 項目 | 狀態 |
| --- | --- |
| 3D 地景 | MapLibre：真實地形、山體陰影、OSM 向量地景（海岸、河流、湖泊、森林）、3D 建築、天空 |
| 行政區 | 真實 38 區外框；只畫區界與區名；點選會飛過去並顯示面積、人口 |
| 模式 | 觀景模式（預設）／指揮模式（地震 72 小時），H 鍵切換 |
| 模擬核心 | 完成：可重現、可重播、可無畫面批次執行 |
| 地震劇本 | 第一版可玩；數值用草稿世界調過，尚未用真實人口重調 |
| 資料管線 | 完成：直接讀國土測繪中心 SHP；人口與斷層尚未接真實資料 |
| 測試 | 39 個；五個套件型別檢查通過 |
| 線上版 | GitHub Pages：推送到 `main` 自動部署；GoatCounter 瀏覽統計 |

## 階段 1：地景精修（約 2–4 週，目前重點）

目標：截圖可以直接當宣傳圖。風格：插畫風（柔和低彩度色塊、地形層次清楚，見 DECISIONS 2026-10-09）。

- [x] **1.1 自有樣式檔**：把 liberty 樣式複製成 `apps/web/src/map/style/`，自己掌握配色（海、河、森林、農地、市區、道路）與字級（配色在 `map/config.ts` 的 `PALETTE`；第一版待看畫面微調）
- [x] **1.2 等高線**：用 DEM 即時產生等高線（`maplibre-contour`），每 50 公尺細線、250 公尺粗線並標高度
- [x] **1.3 山與水的名稱**：山峰標高度；主要河川（高屏溪、二仁溪、楠梓仙溪、荖濃溪、愛河）加粗與命名；湖泊（蓮池潭、澄清湖、美濃湖）命名（河名依 OSM 名稱比對，若有河沒出現要查 OSM 上的實際名稱）
- [x] **1.4 地標導覽**：10 個左右的地標鏡頭（85 大樓、壽山、旗津、蓮池潭、澄清湖、佛光山、美濃、茂林、藤枝、玉山方向），可一鍵依序飛覽（鏡頭座標為約略值，看畫面再微調；30 秒飛覽影片待錄）
- [x] **1.5 光影與時間**：依時段調整太陽方向、天空與霧的顏色；夜間模式（暗色底圖、建築發光）（工具列「時段」：自動／清晨／白天／黃昏／夜晚，設定在 `config.ts` 的 `TIMES`）
- [x] **1.6 載入與效能**：載入畫面改成高雄剪影；在一般筆電與手機上維持流暢；一鍵截圖分享（手機與低階裝置自動進省電模式，網址 `?quality=low|high` 可強制；實機流暢度待使用者在手機上確認）

驗收：每項完成後截圖比較；1.4 完成後錄一段 30 秒飛覽影片。

## 階段 2：真實資料（約 2–3 週）

- [ ] **2.1 人口**：接內政部戶政司「村里戶數、單一年齡人口」CSV，取代約略人口
- [ ] **2.2 活動斷層**：接地質調查及礦業管理中心的活動斷層 SHP，取代示意斷層
- [x] **2.3 醫療與避難**：醫院（含病床數）、避難收容處所的位置，畫成地圖上的點（管線 `--shelters`、`--hospitals`；沒有醫院檔時用 OSM 醫院點；實際資料待使用者下載後執行 `build-world`）
- [x] **2.4 資料版本**：世界檔記錄每份來源資料的版本與日期；資料頁列出來源與授權（`meta.sources`、`meta.builtAt`；版本從檔名的民國日期讀出；畫面上「關於」頁列出）

驗收：`npm run build-world` 一次吃進全部資料；地圖上的資料頁列出每份來源。

## 每項工作的固定流程

1. 開新的 Claude Code 對話，說「做 ROADMAP 的 1.2」
2. Claude 先讀 `CLAUDE.md` 與本檔，說明計畫，你確認後才動手
3. 完成後跑 `npm test`、`npm run typecheck`，你開 `npm run dev` 看畫面並截圖
4. 在本檔把該項打勾，必要時更新 `docs/ARCHITECTURE.md`
