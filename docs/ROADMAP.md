# 開發路線圖

最後更新：2026-10-10

**目前重點（2026-10-10 起）：即時交通。** 在 3D 高雄上即時顯示公車、捷運、輕軌、臺鐵與道路路況，資料來自交通部 TDX；
另有管理後台設定資料串接。**遊戲性（地震 72 小時）暫停開發**，現有功能保留可玩（見 DECISIONS 2026-10-10）。
路線依序是：開發基礎 → 地景精修 → 真實資料 → 遊戲性（暫停）→ **即時交通** → 公開試玩 → 擴張。
每一項都切成能在一次 Claude Code 對話內完成的大小，並寫好驗收方式。

## 階段 1：地景精修（約 2–4 週，目前重點）

目標：截圖可以直接當宣傳圖。風格：插畫風（柔和低彩度色塊、地形層次清楚，見 DECISIONS 2026-10-09）。

- [x] **1.1 自有樣式檔**：把 liberty 樣式複製成 `apps/web/src/map/style/`，自己掌握配色（海、河、森林、農地、市區、道路）與字級（配色在 `map/config.ts` 的 `PALETTE`；第一版待看畫面微調）
- [x] **1.2 等高線**：用 DEM 即時產生等高線（`maplibre-contour`），每 50 公尺細線、250 公尺粗線並標高度
- [x] **1.3 山與水的名稱**：山峰標高度；主要河川（高屏溪、二仁溪、楠梓仙溪、荖濃溪、愛河）加粗與命名；湖泊（蓮池潭、澄清湖、美濃湖）命名（河名依 OSM 名稱比對，若有河沒出現要查 OSM 上的實際名稱）
- [x] **1.4 地標導覽**：10 個左右的地標鏡頭（85 大樓、壽山、旗津、蓮池潭、澄清湖、佛光山、美濃、茂林、藤枝、玉山方向），可一鍵依序飛覽（鏡頭座標為約略值，看畫面再微調；30 秒飛覽影片待錄）
- [x] **1.5 光影與時間**：依時段調整太陽方向、天空與霧的顏色；夜間模式（暗色底圖、建築發光）（工具列「時段」：自動／清晨／白天／黃昏／夜晚，設定在 `config.ts` 的 `TIMES`）
- [x] **1.6 載入與效能**：載入畫面改成高雄剪影；在一般筆電與手機上維持流暢；一鍵截圖分享（手機與低階裝置自動進省電模式，網址 `?quality=low|high` 可強制；實機流暢度待使用者在手機上確認）

驗收：每項完成後截圖比較；1.4 完成後錄一段 30 秒飛覽影片。

## 階段 T：即時交通（目前重點）

目標：在 3D 地景上即時看到高雄的公車、軌道與路況，資料串接可以在後台管理。
架構：交通資料伺服器（`apps/server`）保管 TDX 金鑰、定時抓資料；網頁版只向伺服器要整理好的資料（見 DECISIONS 2026-10-10）。

- [x] **T.1 交通資料格式與 TDX 轉換**（`packages/traffic`：統一格式、公車／捷運／輕軌／臺鐵／路況／公共自行車的 TDX 回應轉換、示範資料）
- [x] **T.2 交通資料伺服器**（`apps/server`：TDX 權杖與排隊呼叫、各來源定時抓取、失敗一分鐘後重試、公開 API `/api/traffic/snapshot`）
- [x] **T.3 管理後台**（`admin.html`：TDX 帳號設定與測試、各來源啟用與更新間隔、立即更新、狀態與紀錄、允許的網站）
- [x] **T.4 交通模式介面**（工具列「即時交通」或 T 鍵：車輛滑動動畫、軌道路線與車站、路況著色、圖層開關、點選看到站時間與車速；沒有伺服器時用示範捷運）
- [x] **T.10 3D 列車**：拉近（zoom 11 以上）時車輛畫成立體車廂（捷運 3 節、輕軌 5 節、臺鐵 8 節、公車 1 節），沿軌道線形彎曲、拉遠自動放大；更遠才是圓點。臺鐵路線線形一併接上（`/v3/Rail/TRA/Shape`）
- [x] **T.11 3D 公車**：公車分車頭段（大擋風玻璃）與車身段，深色底盤、側窗帶，比例比列車細長；示範資料加入 3 條虛構公車路線，沒有 TDX 也看得到
- [x] **T.12 3D 輕軌**：輕軌 5 節低底盤模組（大車窗、模組間連接緊密）；示範資料加入環狀輕軌（22 站約略位置，順行／逆行，班距 15 分鐘）
- [ ] **T.5 實際接上 TDX**：使用者申請 TDX 帳號、在自己電腦執行 `npm run server`，確認各來源都抓得到（雲端開發環境連不到 TDX，這步要在使用者電腦上做）
- [ ] **T.6 伺服器上線**：把交通資料伺服器部署到雲端（例如 Render、Fly.io、Cloudflare），線上版設 `VITE_TRAFFIC_API` 指向它
- [ ] **T.7 列車位置更精準**：用時刻表＋到站資訊推估捷運、臺鐵列車在兩站之間的位置（目前只畫「即將進站」的列車）
- [ ] **T.8 資料量最佳化**：路段線形改成只在變動時下載，平常只傳車速與壅塞程度
- [ ] **T.9 更多資料**：高速公路路況（國道 VD）、停車場剩餘車位、即時事故與施工、公車路線線形

驗收：在使用者電腦上執行伺服器、填入 TDX 帳號後，交通模式出現真實公車與路況，後台各來源顯示正常。

## 每項工作的固定流程

1. 開新的 Claude Code 對話，說「做 ROADMAP 的 1.2」
2. Claude 先讀 `CLAUDE.md` 與本檔，說明計畫，你確認後才動手
3. 完成後跑 `npm test`、`npm run typecheck`，你開 `npm run dev` 看畫面並截圖
4. 在本檔把該項打勾，必要時更新 `docs/ARCHITECTURE.md`
